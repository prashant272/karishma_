# Aarav & Ananya — Royal Indian Wedding Invitation Website

A luxury, cinematic, interactive Indian royal wedding invitation website built with React, Vite, Tailwind CSS, and Framer Motion. Strictly frontend-only with realistic sample data.

---

## 👑 Features Implemented

1. **Opening 3D Envelope Animation (`EnvelopeIntro.jsx`)**:
   - Royal invitation envelope with deep maroon and gold foil finish.
   - Golden royal wax seal monogram ("A&A") with interactive pulsing hover effects.
   - Sacred Lord Ganesha auspicious blessing (*॥ श्री गणेशाय नमः ॥*).
   - "Together With Their Families" & "You Are Cordially Invited".
   - 3D envelope opening with sliding card revelation and golden celebration confetti particles (`canvas-confetti`).
   - Ambient background music toggle (*Auspicious Raag Shehnai synthesis via Web Audio API*).

2. **Hero Section (`HeroSection.jsx`)**:
   - *"Two Souls, One Beautiful Journey"* & *"Together with our families, we invite you to celebrate our special day."*
   - Couple names: **Aarav & Ananya** with royal gold shimmer typography.
   - Real-time animated countdown timer to the wedding date: **15 February 2027**.
   - Couple portrait with ornate golden borders and venue badge.

3. **Family Introduction (`FamilySection.jsx`)**:
   - Two traditional Indian royal wedding columns:
     - **Groom's Family (Rathore Dynasty)**: Grandfather, Grandmother, Father, Mother, Brother, Sister.
     - **Bride's Family (Sharma Lineage)**: Grandfather, Grandmother, Father, Mother, Brother, Sister.
   - Ornate Rajasthani palace corner accents and traditional typography.

4. **Wedding Events & Muhurats (`EventsSection.jsx`)**:
   - Haldi Ceremony
   - Mehendi Ceremony
   - Sangeet Night
   - The Royal Wedding Ceremony (highlighted auspicious badge)
   - Grand Reception
   - Displays: Ceremony Name, Date, Time, Venue, Attire / Dress Code & High-resolution Indian wedding photography.

5. **Our Story Timeline (`StorySection.jsx`)**:
   - Chapter I: Serendipity in Udaipur
   - Chapter II: Letters & Starlit Nights
   - Chapter III: The Regal Proposal
   - Timeline cards with alternating layout and romantic storytelling.

6. **Photo Gallery & Lightbox (`GallerySection.jsx`)**:
   - Masonry-style layout.
   - Golden hover zoom and category tags.
   - Fullscreen Lightbox with Next / Previous image navigation and keyboard/click dismiss.

7. **Venue & Directions (`VenueSection.jsx`)**:
   - Royal Palace & Heritage Grounds, Amer Road, Jaipur, Rajasthan.
   - Google Maps iframe embed with custom royal dark theme.
   - Direct "Get Directions" navigation button.

8. **Interactive RSVP Form (`RSVPSection.jsx`)**:
   - Guest Name, Mobile Number, Number of Guests, Attendance selection, and Blessings / Message.
   - Instant client-side confirmation message with celebratory confetti burst.

9. **Atmospheric Effects**:
   - Continuous floating rose petals simulation across all sections.
   - Indian classical Raag Shehnai instrumental sound synthesizer (Web Audio API with toggle).

---

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Run Vite dev server
npm run dev

# Build production bundle
npm run build
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
